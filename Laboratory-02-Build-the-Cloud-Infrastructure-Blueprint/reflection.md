## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important cloud infrastructure components because they provide the processing power required to run applications and services. Without compute resources, applications would not be able to execute their tasks. During this laboratory, I observed that the KillerCoda environment provided an Intel Xeon E312xx CPU with one CPU core. This helped me understand that even a cloud laboratory environment uses allocated computing resources.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable operating system for cloud servers and virtual machines. It provides powerful command-line tools that allow administrators to inspect and manage system resources. In this laboratory, I used Linux commands such as lscpu, free -h, df -h, hostname, and hostname -I to investigate the cloud server. Linux therefore makes it easier to manage and monitor cloud infrastructure.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure configuration and planned design. It helps engineers understand the resources being used and reduces mistakes during deployment. Documentation also makes it easier to troubleshoot problems and maintain the infrastructure in the future.
