# The Language of Automation

## 1. Bash Script
A Bash script is a file that contains Linux commands arranged to perform tasks automatically. The `#!/bin/bash` line, called a shebang, tells Linux to use Bash to execute the commands in the file.

## 2. Variables
Variables store values that a script can use whenever needed. For example, `$BACKUP_DIR` stores the backup folder name, making the script easier to update without changing every command.

## 3. Cron Job
A cron job is a scheduled task that Linux runs automatically at a specified time. It is useful in cloud operations because it can perform regular backups, maintenance, and monitoring without requiring someone to run commands manually.
