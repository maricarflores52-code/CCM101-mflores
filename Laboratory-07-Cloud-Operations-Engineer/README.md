# Laboratory 07: Cloud Operations Engineer

## Mission Overview

This laboratory focused on monitoring a Linux host and a containerized web application. The activity used system commands, Docker, Nginx, web requests, application logs, and container metrics to check the health of the environment.

## Objectives

The objectives of this laboratory were to monitor CPU, memory, and disk resources, deploy an Nginx web server, generate web traffic, examine application logs, and monitor the container's resource usage.

## Monitoring Commands Executed

The following commands were used during the laboratory:

- free -h
- df -h
- top
- docker run
- curl
- docker logs
- docker stats

These commands provided information about the host system and the running Nginx container.

## Skills Learned

This laboratory improved my skills in Linux system monitoring, Docker container management, web server testing, log analysis, and real-time resource monitoring. I also learned how monitoring information can help identify possible problems in a cloud environment.
