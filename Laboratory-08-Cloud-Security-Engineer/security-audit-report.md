# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to perform their tasks. It helps protect cloud accounts by limiting unauthorized access and reducing the damage caused by compromised accounts.

## 2. Attack Surface

The attack surface refers to all the possible entry points that attackers can use to access a server or system. Open ports, outdated software, and weak passwords can increase the attack surface and make the server easier to attack.

## 3. Default Deny Policy

A Default Deny policy blocks incoming connections unless they are specifically allowed. This approach is safer because it prevents unnecessary access and allows administrators to control which services can communicate with the server.
