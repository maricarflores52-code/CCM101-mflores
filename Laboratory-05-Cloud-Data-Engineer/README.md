# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focuses on cloud object storage and the deployment of MinIO. The activity simulates a storage requirement for a photo-sharing application where a large number of images need to be stored outside the web server container.

Using Docker and the KillerCoda Playground, an S3-compatible MinIO server was deployed. The activity also involved accessing its web interface, creating a bucket, and uploading a sample object.

## Objectives

- Understand the differences among Block, File, and Object Storage.
- Set up MinIO through Docker.
- Use port forwarding to access a cloud service.
- Create a storage bucket and upload a file.
- Record the cloud storage procedures using Markdown.
- Add the laboratory activity to the GitHub cloud portfolio.

## Tools Used

- KillerCoda
- Ubuntu
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Comparing different cloud storage methods.
- Deploying MinIO inside a Docker container.
- Configuring container environment variables.
- Accessing services through a forwarded port.
- Creating and using an object storage bucket.
- Uploading files through a cloud storage interface.
- Creating technical documentation using Markdown.
